## 1. 백엔드 오류 확인

### 1.1 "비활성화된 계정입니다" (COMMON-005) 오류 분석

**원인 파악:**
- 백엔드에서 `UserStatus.SUSPENDED` 상태의 사용자가 API 호출 시 발생
- `ErrorCode.ACCOUNT_SUSPENDED` (ACCOUNT-014) 또는 `ErrorCode.INVALID_MEMBER` (COMMON-005)

**발생 위치:**
- `UserDetailService.java:33-34` - Spring Security 사용자 로드 시
- `AuthServiceImpl.java:139` - 로그인 시
- `AuthServiceImpl.java:221` - 닉네임/전화번호로 사용자 검색 시
- `AuthServiceImpl.java:269, 310` - 비밀번호 재설정/변경 시

**결론:** 백엔드 DB에서 비활성화된 사용자 데이터 정리 필요

## 2. 프론트엔드 API 정리

### 2.1 사용하지 않는 API 파일 삭제

| 파일 | 상태 | 사유 |
|------|------|------|
| `src/api/petApi.ts` | **삭제** | 프론트엔드에서 미사용 |

### 2.2 apiConfig.ts 누락된 엔드포인트 추가

**문제:** `manageApi.ts`, `adminApi.ts`에서 참조하는 엔드포인트가 `apiConfig.ts`에 없어서 크래시 발생

**수정 내용:**
```typescript
// 관리자 (Admin/Manage) - manageApi.ts에서 사용
manage: {
  getAllUsers: '/admin/members',
  getUserDetail: '/admin/members/:id',
  updateUser: '/admin/members/:id',
  deactivateUser: '/admin/members/:id/deactivate',
  activateUser: '/admin/members/:id/activate',
},

// 관리자 (Admin) - adminApi.ts에서 사용
admin: {
  members: '/admin/members',
  memberDetail: '/admin/members/:memberId',
  cards: '/admin/card',
  sendCustomNotification: '/admin/send/custom',
  sendDiaryNotification: '/admin/send/diary',
  sendReportNotification: '/admin/send/report',
},
```

### 2.3 reant 엔드포인트 제거

`petApi.ts` 삭제에 따라 `apiConfig.ts`에서 `reant` 엔드포인트 제거
