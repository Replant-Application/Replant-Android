# 커뮤니티 글과 댓글 숨기기 기능 구현 계획

## 목표
사용자가 특정 게시글과 댓글을 숨겨 더 이상 보이지 않도록 하는 기능 구현

## 구현 방식
- **프론트엔드 로컬 저장**: AsyncStorage를 사용하여 기기 로컬에 숨긴 컨텐츠 ID 목록 저장
- **필터링**: 게시글/댓글 목록 표시 시 숨긴 ID 제외

## 구현 세부사항

### UI/UX 패턴
1. **메뉴 아이콘**: PostCard는 기존 "⋮" 메뉴 버튼 활용
2. **메뉴 아이템 스타일**: 기존 수정/삭제 메뉴와 동일한 스타일
   - 이모지 아이콘: "👁️‍🗨️" 또는 "🚫"
   - 텍스트: "숨기기"
   - 색상: `colors.text.primary` (기본 텍스트 색상)
3. **확인 다이얼로그**: Alert.alert 사용
   - 제목: "게시글 숨기기" / "댓글 숨기기"
   - 메시지: "이 게시글을 숨기시겠습니까? 숨긴 게시글은 목록에서 보이지 않습니다."
   - 버튼: "취소", "숨기기" (destructive 스타일 아님, 일반 텍스트)

### 데이터 저장 형식
```typescript
// AsyncStorage에 저장되는 형식
{
  "hiddenPosts": ["post_id_1", "post_id_2", ...],
  "hiddenComments": ["comment_id_1", "comment_id_2", ...]
}
```

### 필터링 로직
```typescript
// CommunityScreen
const filteredPosts = useMemo(() => {
  let allPosts = [...posts, ...convertedVerificationPosts];
  
  // 숨긴 글 필터링
  allPosts = allPosts.filter(post => !hiddenPostIds.includes(post.post_id));
  
  // 기존 필터링 로직...
}, [posts, hiddenPostIds, ...]);

// CommunityPostDetailScreen
{comments
  .filter(comment => !comment.parent_comment_id)
  .filter(comment => !hiddenCommentIds.includes(comment.comment_id))
  .map(...)}
```
